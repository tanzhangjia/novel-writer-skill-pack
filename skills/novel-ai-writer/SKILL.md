# novel-ai-writer

## 文件格式
- **源文件**：`草稿/{副本名}-{序号} {关键词}.md`
- **最终成品**：也是 `.md`，草稿即定稿
- **不再生成 doc**

## 项目结构

```
novel-ai-xiaofa/
├── 大纲/         # 全书架构、章节目录、副本设计
├── 设计沉淀/     # 对话讨论中提炼的设定/规则/要求
├── 主要事项/     # 角色、诡异、写作原则
├── 评审/         # 读者评审（独立于正文）
├── 灵感/         # 每日脑暴产出
├── 记忆/         # 续写日志、反思日志
└── 草稿/         # 所有章节 .md（源文件=成品）
```

## 写作流程（每章六步）

```
规划 → 大纲确认 → 写正文 → 自检 → 三阶段审查 → 提交
```

### 第一步：读上下文
读最近3章草稿 + 以下设定文件：
- 大纲/全本大纲.md（注意末尾状态标记规则，已完结不修改）
- 大纲/副本设计模板.md
- 大纲/章节目录.md（检查当前进度）
- 记忆/YYYY-MM-DD-续写日志.md
- 记忆/反思日志.md（最新反思要求）
- 主要事项/角色设定.md、诡异设定.md、写作基本原则.md、续写参考.md
- 灵感/ 目录最新文件
- **设计沉淀/ 目录最新文件**（对话中提炼的设定/规则/要求，必须落实）

### 第二步：写章节大纲
写正文前先输出大纲，确认本章规划：

```markdown
## 第X章 大纲
- **核心任务**：这一章要完成什么
- **场景规划**：几个场景、在哪
- **人物动向**：谁出场、做什么
- **节奏安排**：起→承→转→合
- **情感弧线**：从什么情绪到什么情绪
- **伏笔处理**：埋什么、收什么
- **预计字数**：2000~4000字
- **前后连贯**：前接第X章Y设定，后引
```

### 第三步：写正文
- `草稿/{副本名}-{序号} {关键词}.md`
- 正文不写章节标题
- 遵守写作风格规则

### 第四步：自检清单
```
□ 核心任务完成
□ 场景转换自然
□ 对话符合人设（柱子口语化、白夜说半句、小发豆包风）
□ 每章至少一段不带"他说""她问"
□ 有钩子/爽点，看完想点下一章
□ 字数在2000~4000
□ 无直白脏话（用网络梗替代）
□ 主角可以有盲区/犯错
□ 环境描写压缩到3行内
```

### 第五步：三阶段审查
1. **大纲审查** — 是否偏离原定规划
2. **语言审查** — 流畅度、重复词、节奏
3. **质量审查** — 整体评级+优化建议

审查结果写入 `评审/{章节名}.md`

### 第六步：提交
1. 根据审查建议优化正文
2. 更新章节目录 — `大纲/章节目录.md`
3. 追加续写日志 — `记忆/YYYY-MM-DD-续写日志.md`（字数、剧情概要、关键设定、暗线、死亡/登场玩家）
4. 输出摘要

## 字数规则
每章建议 2000~4000 字，不超过 5000。

## 写作规则
- 龙国架空背景，诡异游戏体系
- 小发豆包风，柱子口语化（网络梗，不要直白脏话），秦浩可以有盲区
- 白夜说话只说半句
- 人味写作规则见 `写作基本原则.md`
