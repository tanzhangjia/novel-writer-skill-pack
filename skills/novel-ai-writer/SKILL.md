# Novel AI Writer Skill

## 写作流程（每章六步）
规划 → 大纲确认 → 写正文 → 自检 → 三阶段审查 → 提交

### 第一步：读上下文
读最近3章+大纲+写作指南+读者反馈，明确当前章节位置。

### 第二步：写章节大纲
先输出大纲给用户确认：
- 核心任务、场景规划、人物动向、节奏安排、情感弧线、伏笔处理、预计字数

### 第三步：写正文
草稿/{副本名}-{序号} {关键词}.md，正文不写章节标题。

### 第四步：自检清单
□ 核心任务完成 □ 场景转换自然 □ 对话符合人设
□ 有钩子/爽点 □ 字数2000~4000 □ 无直白脏话
□ 主角有盲区/犯错 □ 至少一段不带"他说"的对话

### 第五步：三阶段审查
1. 大纲审查 → 2. 语言审查 → 3. 质量审查
写入 评审/{章节名}.md

### 第六步：提交
更新章节目录、续写日志、Git commit。

## 风格要求
- 主角可以有盲区，对话不加"他说""她问"
- 口语化表达，环境描写压缩到3行
- 每章结尾留钩子
