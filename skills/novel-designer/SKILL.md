# 副本设计技能

一次性完成副本的完整设计方案，不等脑暴慢慢挤。

## 触发时机

- **主动调用**：你说"设计下一个副本"时
- **续写任务**：读 `大纲/设计.md` 发现副本二是⬜待设计时，优先触发此skill

## 设计流程

### 第一步：读上下文
- `大纲/设计.md` — 了解已完成副本的风格，保证差异化
- `大纲/全本大纲.md` — 第一卷的整体节奏
- `设计沉淀/` 最新文件 — 狩猎收获/编辑评估中提到的爽点要求
- `主要事项/角色设定.md` — 小发现阶段、已有工具诡
- `大纲/章节目录.md` — 第16章的故事落点

### 第二步：一次性设计完整副本

设计包含以下全部内容，缺一不可：

```
## 副本二 ✅ [副本名称]（设计完成）

### 基础信息
- 副本等级、场景、面积
- 入场方式、玩家人数
- 核心规则（白天/夜晚规则、特殊机制）
- 时间线

### 地图与区域
- 主要区域划分（3~5个区域）
- 每个区域的规则和危险等级
- 安全区位置

### 玩家生态（10~15人）
- 主要队友（2~3人，有名字有天赋）
- 对手/中立（2~3人）
- 炮灰组（4~6人，带死亡方式设计）

### 核心诡物/BOSS
- 名称、外观、能力机制
- 战斗阶段（2~3阶段）
- 弱点设计

### 剧情推进（10~15章规划）
- 第一阶段（第1~4章）
- 第二阶段（第5~8章）
- 第三阶段（第9~12章）
- BOSS战+结算（第13~15章）

### 小发在这个副本中的进化
- 当前能力上限
- 安排进化节点（工具诡获取/参数解锁/窗口扩容）

### 暗线铺设（3~5条）
- 深红主线推进
- 白夜线索
- 角色关系
- 世界观补充

### 过渡章节（第17~19章）
- 返回现实做什么
- 关键线索处理
- 如何进入新副本
```

### 第三步：写入
写入 `大纲/设计.md`，完整替换副本二的内容，标记为 ✅ 设计完成。
