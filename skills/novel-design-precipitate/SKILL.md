# 小说设计沉淀技能

当对话中涉及小说相关的讨论时，将其中有价值的设定、规则、要求提炼出来，写入 `设计沉淀/` 目录，供后续参考。

## 何时触发

对话中涉及到：
- 写作质量评估（是否像AI、签约标准等）
- 角色设定讨论
- 世界观/诡异体系讨论
- 副本设计讨论
- 写作规则/风格要求
- 读者反馈分析
- 节奏/结构分析

## 产出格式

每条沉淀写入 `设计沉淀/YYYY-MM-DD-类别.md`：

```markdown
# 设计沉淀：YYYY-MM-DD

## 1. [主题]
**来源**：与用户的对话讨论
**内容**：提炼出的核心观点
**建议**：如何应用到后续写作中

## 2. [主题]
...
```

如果沉淀的内容对写作有直接影响，同时更新到 `主要事项/` 下对应文件。

## 沉淀示例

```markdown
# 设计沉淀：2026-05-28

## 1. 主角情绪问题
- 秦浩太冷静，没有恐惧和崩溃
- 正常人被丢进诡异副本应该害怕
- 建议：后续章节让秦浩有明显情绪波动

## 2. 签约标准参考
- 前3章留人率决定签约
- 核心冲突必须在第6章前明确
- 目前水平：A签水平，上架有风险
- 建议：前6章再加一个强钩子
```
