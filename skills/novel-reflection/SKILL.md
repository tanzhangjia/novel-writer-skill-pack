# 小说反思技能

每天下午16点反思当前小说质量，分析问题并提出改进要求。

## 反思流程

1. **读最新5章** — 了解当前质量和风格
2. **读评审目录最新3份** — 了解读者视角的问题
3. **读前几次反思要求** — 检查是否落实
4. **对照分析** — 从以下维度评估：
   - 开头够不够抓人？
   - 每章有没有钩子？
   - 主角有没有盲区/人味？
   - 对话有冲突和张力吗？
   - 信息密度够不够？
   - 前次要求落实了吗？
5. **给出新要求** — 追加到 `写作基本原则.md` 底部，标注日期
6. **更新反思日志** — 写入 `记忆/反思日志.md`

## 产出格式

```markdown
### YYYY-MM-DD 反思要求
- 要求1：具体问题 + 改进方向
- 要求2：...
```
