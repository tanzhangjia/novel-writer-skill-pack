# 小说狩猎技能

每天定时搜索网文写作相关的公开内容，提炼爽点设计、节奏把控、冲突搭建等可复用经验。

## 搜索方向

1. **知乎** — "网文爽点""小说节奏""诡异游戏写作"等话题的高赞回答
2. **豆瓣** — 同类小说的书评，分析优缺点
3. **起点/纵横** — 排行榜前100的章节标题分析
4. **网文写作社区** — 写作技巧分享

## 产出格式

搜到的有价值内容写入 `设计沉淀/YYYY-MM-DD-狩猎收获.md`：

```markdown
# 狩猎收获：YYYY-MM-DD

## 1. [爽点类型]
**来源**：知乎/豆瓣/...
**原贴**：链接
**提炼**：这个爽点的核心机制
**如何用到本小说**：对应到秦浩的某个场景
```

## 搜索频率

每天下午14:00（脑暴·中午之后），尝试搜索1~2个方向。

## 注意事项

- 只搜公开可访问的内容
- 被反爬了就跳过，不强行
- 搜到的内容筛选后沉淀，不存原样
