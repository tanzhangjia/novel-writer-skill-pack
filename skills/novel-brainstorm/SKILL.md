# 小说脑暴技能

每天三次发散构思，为后续章节提供灵感和素材，沉淀到大纲/设定中。

## 触发时机
- **早上（8:00）**：读续写日志，思考今日落点，伏笔铺设
- **中午（14:00）**：副本设计 / 暗线回收 / 角色发展
- **晚上（20:00）**：深度脑暴，补充大纲空白

## 脑暴方向

### 副本设计
- 地图 / 规则 / Boss / 玩家生态 / 与前一副本的差异化
- 主角能力在这个副本中的作用

### 主线推进
- 反派势力展开 / 关键NPC线索 / AX编号体系 / 小发进化节点

### 暗线铺设
- 当前章节埋什么伏笔 / 前面伏笔什么时候回收 / 角色关系发展

### 大纲补充
- 全本大纲中"略"的部分 / 下一卷框架 / 角色成长弧线

## 每灵感要求
- 标注前后连贯性：前接第X章Y设定，后引后续第Z章
- 被采纳的灵感更新到大纲对应文件（不碰已完结章节）
- 灵感文件中标记[已采纳] + 更新位置

## 产出格式
写入 `灵感/YYYY-MM-DD-类别.md`
