# 网文写作技能包 - OpenClaw Skill Pack

三组 AI 驱动的网文写作技能。

| Skill | 功能 | 频率 |
|-------|------|------|
| `novel-ai-writer` | 自动续写 | 每天6:00 |
| `novel-brainstorm` | 发散构思 | 早8/中14/晚20 |
| `novel-reflection` | 质量反思 | 每天16:00 |

## 写作流程

规划 → 大纲确认 → 写正文 → 自检 → 审查 → 提交

## 安装

1. 三个 skill 放到 `~/.openclaw/workspace/skills/`
2. 创建 `大纲/ 草稿/ 评审/ 灵感/ 记忆/ 主要事项/` 目录
3. 写入你的设定文件
4. 配置 cron 任务
